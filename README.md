# Заметки для Zepp OS (Amazfit Cheetah Square)

Приложение-заметки для часов на Zepp OS: текст, заголовки, **формулы LaTeX**,
**фотографии** и **страницы PDF**. Заметки пишутся на телефоне (в приложении Zepp),
а читаются на часах, в том числе без связи с телефоном.

```
┌──────────── телефон (приложение Zepp) ────────────┐        ┌──── часы ────┐
│ Настройки (setting/)   ── settingsStorage ──▶     │        │ page/index   │
│   редактор заметок                                │  BLE   │  список      │
│ Side service (app-side/)                          │◀──────▶│ page/note    │
│   разбор разметки → LaTeX/фото/PDF → PNG          │ файлы  │  просмотр    │
│   → конвертация → передача файлов на часы         │───────▶│ data://…png  │
└──────────────┬────────────────────────────────────┘        └──────────────┘
               │ HTTP
     latex.codecogs.com / images.weserv.nl   или   свой tools/render_server.py
```

## Возможности

| Что | Как пишется в заметке | Нужен сервер? |
|---|---|---|
| Заголовок | `# Заголовок` | нет |
| Формула (блок) | `$$ \int_0^1 x^2\,dx = \frac13 $$` | нет (codecogs), но с сервером лучше |
| Формула в строке | `$E=mc^2$` (рисуется отдельной картинкой) | нет |
| Фото | `![подпись](https://…/photo.jpg)` | нет (weserv), с сервером без чёрных полей |
| PDF целиком | `[pdf](https://…/file.pdf)` (до 30 стр.) | **да** |
| Страницы PDF | `[pdf:3-5](https://…/file.pdf)` или `[pdf:7](…)` | **да** |
| Знак доллара | `\$` | — |

На часах:
- список заметок с превью, кнопка «⟳ Синхронизировать»;
- просмотр с прокруткой; картинки сохраняются на часах и доступны офлайн;
- удаление заметки (двойное нажатие на «Удалить»);
- «+ Быстрая заметка» с экранной клавиатуры — появляется только на прошивках,
  где есть `createKeyboard` (Zepp OS 4+); на остальных кнопка скрыта.

## Сборка и установка

Нужны Node.js 18+ и [Zeus CLI](https://docs.zepp.com/docs/guides/tools/cli/).

```bash
npm i -g @zeppos/zeus-cli
```

```bash
npm install
```

```bash
zeus build
```

Установка на часы в режиме разработчика (в приложении Zepp: Профиль → Настройки →
О программе → 7 раз нажать на логотип → «Режим разработчика»):

```bash
zeus preview
```

`zeus preview` попросит войти в аккаунт Zepp и покажет QR-код — отсканируйте его в
приложении Zepp (Профиль → Режим разработчика → Сканировать).

> `appId` в `app.json` (`1099001`) — временный. Для публикации или стабильной
> установки создайте приложение на [console.zepp.com](https://console.zepp.com) и
> подставьте свой `appId`.

## Как пользоваться

1. Zepp на телефоне → Профиль → ваши часы → Приложения → «Заметки» → **Настройки**.
2. «+ Новая заметка» → заполните заголовок и текст. Поля «+ Формула / + Фото / + PDF»
   дописывают нужную разметку в конец заметки.
3. Откройте «Заметки» на часах — синхронизация начнётся сама (или нажмите «⟳»).
   Пока картинки грузятся, на их месте видна рамка «загрузка…».

**Фото из галереи телефона.** Настройки Zepp не умеют открывать галерею, поэтому
фото добавляется по прямой ссылке. Например: загрузите снимок на любой хостинг
картинок или положите в папку рядом с `render_server.py` и раздайте её как
`python3 -m http.server`.

## Сервер рендеринга (для PDF и качественного LaTeX)

`tools/render_server.py` — маленький HTTP-сервер на Python (Pillow, PyMuPDF,
matplotlib). Он отдаёт PNG ровно под ширину экрана (350 px) и сообщает размеры,
поэтому вёрстка на часах получается точной.

```bash
pip install -r tools/requirements.txt
```

```bash
python3 tools/render_server.py --host 0.0.0.0 --port 8787
```

В настройках приложения укажите адрес, доступный с телефона, например
`http://192.168.1.10:8787` (компьютер в той же Wi-Fi-сети) или адрес сервера в
интернете. Флаг `--usetex` включает полноценный LaTeX (нужен установленный TeX Live);
без него формулы рисует встроенный mathtext из matplotlib (поддерживает
большинство математических команд: дроби, интегралы, суммы, индексы, греческие
буквы, `\mathbb`, и т.п.). Многострочные формулы — через `\\`.

API сервера:

```
GET /render?kind=latex&tex=…&display=1&w=350
GET /render?kind=image&url=…&w=350
GET /render?kind=pdf&url=…&from=1&to=5&w=350
  → {"items":[{"url":"/img/<id>.png","w":350,"h":496,"page":1}],"pages":12}
```

## Структура

```
app.json              манифест (квадратные экраны 390×450, API 3.0)
app.js                приложение (ZML BaseApp)
page/index.js         часы: список заметок, синхронизация
page/note.js          часы: просмотр заметки
utils/store.js        часы: хранение заметок и картинок (@zos/fs)
utils/ui-kit.js       часы: вёрстка «колонкой», карточки, кнопки
app-side/index.js     телефон: side service — разбор, рендер, передача файлов
setting/index.js      телефон: экран настроек / редактор заметок
shared/markup.js      разбор разметки заметок (общий код)
shared/config.js      константы
tools/render_server.py  сервер рендеринга LaTeX / фото / PDF
tools/test-markup.mjs   тесты парсера (npm test)
```

## Ограничения

- Без сервера PDF не отображается (в заметке появится пояснение).
- Через codecogs размер формулы заранее неизвестен; на прошивках без
  `getImageInfo` высота формулы оценивается приблизительно.
- Длинная формула шире 350 px обрезается справа — перенесите её через `\\`
  (при работе через свой сервер формула уменьшается автоматически).
- Картинки передаются по Bluetooth: большой PDF (30 страниц) грузится заметное время.
- Проверено: парсер (тесты), сервер рендеринга, сборка `zeus build`. На реальных
  часах и в симуляторе приложение в этом окружении не запускалось.
