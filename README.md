# Заметки для Zepp OS (Amazfit Cheetah Square)

Приложение-заметки для часов на Zepp OS: текст, заголовки, **формулы LaTeX**,
**фотографии** и **страницы PDF**. Заметки пишутся на телефоне (в приложении Zepp),
а читаются на часах, в том числе без связи с телефоном.

```
┌──────────── телефон (приложение Zepp) ────────────┐        ┌──── часы ────┐
│ Настройки (setting/)   ── settingsStorage ──▶     │        │ page/index   │
│   редактор заметок                                │  BLE   │  список      │
│ Side service (app-side/)                          │◀──────▶│ page/note    │
│   разбор разметки → LaTeX/фото/PDF → PNG          │ файлы  │  просмотр    │
│   → конвертация → передача файлов на часы         │───────▶│ data://…png  │
└──────────────┬────────────────────────────────────┘        └──────────────┘
               │ HTTP
     latex.codecogs.com + images.weserv.nl  (или свой tools/render_server.py)
```

## Возможности

| Что | Как пишется в заметке |
|---|---|
| Заголовок | `# Заголовок` |
| Формула (блок) | `$$ \int_0^1 x^2\,dx = \frac13 $$` |
| Формула в строке | `$E=mc^2$` (рисуется отдельной картинкой) |
| Фото | `![подпись](ссылка)` |
| PDF целиком | `[pdf](ссылка)` (до 30 стр.) |
| Страницы PDF | `[pdf:3-5](ссылка)` или `[pdf:7](ссылка)` |
| Знак доллара | `\$` |

Ссылкой может быть прямая ссылка на файл **или ссылка «Поделиться» из Google Диска,
Яндекс Диска или Dropbox** — она сама превращается в прямую.

Компьютер и свой сервер не нужны: формулы рисует `latex.codecogs.com`, фото и
страницы PDF — `images.weserv.nl` (он же сообщает размеры и число страниц, поэтому
вёрстка на часах точная). Всё это делает Zepp на телефоне.

На часах:
- список заметок с превью, кнопка «⟳ Синхронизировать»;
- просмотр с прокруткой; картинки сохраняются на часах и доступны офлайн;
- удаление заметки (двойное нажатие на «Удалить»);
- «+ Быстрая заметка» с экранной клавиатуры — только на прошивках, где есть
  `createKeyboard` (Zepp OS 4+); на остальных кнопка скрыта.

## Установка только с телефона (Android)

Сборку делает GitHub Actions — при каждом push в репозиторий. Компьютер не нужен.

1. **Включите GitHub Pages** (один раз): в браузере телефона откройте репозиторий →
   Settings → Pages → Source: **GitHub Actions**.
2. **Влейте ветку в `main`** (страница установки публикуется только из основной ветки):
   в приложении GitHub откройте Pull request из ветки с приложением и нажмите Merge.
3. Дождитесь зелёной галочки во вкладке **Actions** (~2 мин).
4. В Zepp включите **режим разработчика**: Профиль → Настройки → О программе →
   7 раз нажмите на логотип Zepp.
5. Откройте страницу установки `https://<ваш-логин>.github.io/zepp_notes/`
   (логин маленькими буквами) и выберите способ:
   - нажмите **«Установить в Zepp»** — если Zepp перехватит ссылку `zpkd1://…`,
     установка начнётся сразу;
   - или Zepp → Профиль → Режим разработчика → **сканер** → QR-код. Свой же экран
     сканер не видит: откройте страницу на любом другом экране (планшет, ТВ, чужой
     телефон) или, если в сканере есть кнопка «Альбом», сохраните QR-картинку и
     выберите её.
6. Без Pages: тот же пакет и запасной QR лежат в релизе **latest-build**
   (вкладка Releases) — он обновляется при сборке из любой ветки.

> `appId` в `app.json` (`1099001`) временный. Для публикации в магазине создайте
> приложение на [console.zepp.com](https://console.zepp.com) и подставьте свой `appId`.

## Как пользоваться

1. Zepp → Профиль → ваши часы → Приложения → «Заметки» → **Настройки**.
2. «+ Новая заметка» → заголовок и текст. Поля «+ Формула / + Фото / + PDF»
   дописывают нужную разметку в конец заметки.
3. **Фото из галереи / PDF из «Файлов»:** «Поделиться» → Google Диск / Яндекс Диск /
   Dropbox → включить доступ по ссылке → скопировать ссылку → вставить в «+ Фото»
   или «+ PDF».
4. Откройте «Заметки» на часах — синхронизация начнётся сама (или нажмите «⟳»).
   Пока картинки грузятся, на их месте видна рамка «загрузка…».

## Свой сервер рендеринга (необязательно)

`tools/render_server.py` (Python: Pillow, PyMuPDF, matplotlib) делает то же, что
публичные сервисы, но у вас: пригодится, если файлы не должны уходить на сторонние
сайты. Его адрес вводится в настройках приложения; пустое поле = публичные сервисы.

```bash
pip install -r tools/requirements.txt
```

```bash
python3 tools/render_server.py --host 0.0.0.0 --port 8787
```

## Структура

```
app.json              манифест (квадратные экраны 390×450, API 3.0)
app.js                приложение (ZML BaseApp)
page/index.js         часы: список заметок, синхронизация
page/note.js          часы: просмотр заметки
utils/store.js        часы: хранение заметок и картинок (@zos/fs)
utils/ui-kit.js       часы: вёрстка «колонкой», карточки, кнопки
app-side/index.js     телефон: side service — разбор, рендер, передача файлов
setting/index.js      телефон: экран настроек / редактор заметок
shared/markup.js      разбор разметки заметок (общий код)
shared/config.js      константы
shared/sources.js     ссылки на codecogs/weserv, облачные диски
.github/workflows/build.yml  сборка в облаке + страница установки
tools/ci-package.mjs  пакет для Cheetah Square + QR-коды
tools/render_server.py  сервер рендеринга LaTeX / фото / PDF
tools/test-markup.mjs   тесты парсера (npm test)
```

## Ограничения

- Нужен интернет на телефоне во время синхронизации; файлы проходят через
  codecogs/weserv (если это неприемлемо — свой сервер).
- Формула шире 350 px уменьшается; очень длинную лучше разбить на несколько `$$…$$`.
- Картинки передаются по Bluetooth: 30 страниц PDF грузятся заметное время.
- Проверено: тесты парсера и ссылок, реальные запросы к codecogs/weserv
  (формулы, фото, PDF, ошибки), сборка `zeus build`, извлечение пакета для
  Cheetah Square. На реальных часах приложение не запускалось; открытие ссылки
  `zpkd1://` кнопкой и загрузка с Google/Яндекс Диска не проверены.
