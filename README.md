# Заметки для Zepp OS (Amazfit Cheetah Square)

Заметки на часах: текст, заголовки, **формулы LaTeX**, **фотографии** и **страницы PDF**.
Работает **полностью офлайн**: телефон сам превращает файлы в готовые картинки и
передаёт их на часы по Bluetooth, а часы хранят всё у себя и показывают без телефона.

```
┌──────────────────────── телефон (Android) ─────────────────────────┐      ┌──── часы ─────┐
│ Папка «ZeppNotes»: конспект.md, лекция.pdf, фото.jpg               │      │ page/index    │
│        │                                                           │      │  список       │
│        ▼                                                           │      │               │
│ Termux: tools/render_server.py  (127.0.0.1:8787, без интернета)    │      │ page/note     │
│   LaTeX → PNG (matplotlib) · PDF → PNG (mutool) · фото → PNG       │      │  просмотр     │
│        │ HTTP внутри телефона                                      │ BLE  │               │
│        ▼                                                           │─────▶│ data://…png   │
│ Zepp: side service (app-side/) → image.convert → передача файлов   │      │ notes.json    │
│ Zepp: настройки (setting/) — редактор заметок                      │      └───────────────┘
└────────────────────────────────────────────────────────────────────┘
```

Встроенная в Zepp часть приложения (side service) не умеет рисовать и не видит файлы
телефона — поэтому картинки готовит маленькая программа на Python в Termux. Ей не нужен
интернет: всё происходит внутри телефона.

## Что можно класть в папку ZeppNotes

| Файл | Что будет на часах |
|---|---|
| `лекция.pdf` | заметка со страницами PDF (первые 30) |
| `фото.jpg` / `.png` / `.webp` | заметка-фото |
| `конспект.md` / `.txt` | текстовая заметка; строка `# …` в начале — заголовок |

Разметка в `.md` и в заметках из настроек Zepp:

| Что | Как писать |
|---|---|
| Заголовок | `# Заголовок` |
| Формула (блок) | `$$ \int_0^1 x^2\,dx = \frac13 $$` (строки — через `\\`) |
| Формула в строке | `$E=mc^2$` |
| Фото из папки | `![подпись](file:фото.jpg)` |
| PDF из папки | `[pdf](file:лекция.pdf)`, `[pdf:31-60](file:лекция.pdf)`, `[pdf:7](file:лекция.pdf)` |
| Знак доллара | `\$` |

Имена файлов могут содержать пробелы и кириллицу.

## Установка (один раз нужен интернет)

### 1. Termux и рендерер
1. Установите **Termux из F-Droid** (версия из Google Play устарела). Для автозапуска
   после перезагрузки можно поставить ещё **Termux:Boot** (тоже F-Droid).
2. В Termux выполните:

```bash
curl -fsSLO https://raw.githubusercontent.com/Xxxkat10xxX/zepp_notes/claude/sharp-turing-mpom9u/tools/termux-setup.sh
```

```bash
bash termux-setup.sh
```

Скрипт поставит `python`, `python-pillow`, `mupdf-tools`, `matplotlib`, попросит доступ к
памяти, создаст папку **ZeppNotes** с примером заметки и команду `zepp-notes`.

3. Запуск рендерера (оставьте Termux работать в фоне):

```bash
zepp-notes
```

В настройках Android отключите для Termux оптимизацию батареи, иначе система может его
усыпить.

### 2. Приложение на часы
Сборку делает GitHub Actions (вкладка **Actions**); пакет для Cheetah Square лежит в
релизе **latest-build** (вкладка Releases), а при включённом GitHub Pages
(Settings → Pages → Source: GitHub Actions) — на странице
`https://xxxkat10xxx.github.io/zepp_notes/` с кнопкой и QR-кодом.

1. Zepp → Профиль → Настройки → О программе → 7 раз нажмите на логотип
   (режим разработчика).
2. Профиль → Режим разработчика → сканер → QR-код со страницы установки
   (с другого экрана, либо через кнопку «Альбом» в сканере, если она есть), или нажмите
   на странице «Установить в Zepp».

> `appId` в `app.json` (`1099001`) временный; для публикации в магазине нужен свой
> с [console.zepp.com](https://console.zepp.com).

## Как пользоваться

1. Скопируйте PDF / фото в папку **ZeppNotes** («Файлы» → Копировать, или
   «Поделиться» → Сохранить в файлы) или напишите `.md` в любом текстовом редакторе.
2. Убедитесь, что в Termux запущен `zepp-notes`.
3. Откройте «Заметки» на часах — синхронизация начнётся сама (или «⟳»). Пока картинки
   передаются, на их месте видна рамка «загрузка…».
4. После этого всё доступно на часах без телефона.

Короткие заметки можно писать и прямо в Zepp: Профиль → часы → Приложения → «Заметки» →
Настройки. Если рендерер не запущен, часы показывают последнюю сохранённую копию и
пишут, что нужно запустить `zepp-notes`.

## Структура

```
app.json                манифест (квадратные экраны 390×450, API 3.0)
app.js                  приложение (ZML BaseApp)
page/index.js           часы: список заметок, синхронизация
page/note.js            часы: просмотр заметки
utils/store.js          часы: хранение заметок и картинок (@zos/fs)
utils/ui-kit.js         часы: вёрстка «колонкой», карточки, кнопки
app-side/index.js       телефон (Zepp): разбор заметок, получение PNG, передача на часы
setting/index.js        телефон (Zepp): экран настроек / редактор заметок
shared/markup.js        разбор разметки заметок (общий код)
shared/config.js        константы
tools/render_server.py  телефон (Termux): офлайн-рендер LaTeX / фото / PDF, папка ZeppNotes
tools/termux-setup.sh   установка рендерера в Termux
tools/test-markup.mjs   тесты парсера (npm test)
tools/ci-package.mjs    CI: пакет для Cheetah Square + QR-коды
.github/workflows/build.yml  сборка в облаке
```

## Ограничения и что проверено

- Формулы рисует mathtext из matplotlib — это большая часть математического LaTeX
  (дроби, корни, интегралы, суммы, индексы, греческие буквы, `\mathbb`, …), но не
  окружения вроде `align`/`matrix` и не TikZ.
- Картинки идут по Bluetooth: 30 страниц PDF передаются заметное время; потом всё на часах.
- Проверено в этом окружении: тесты парсера; рендерер (папка, имена с пробелами и
  кириллицей, формулы, фото, PDF через PyMuPDF и логика пути через `mutool` на эмуляторе,
  защита от выхода за пределы папки, запрет интернет-ссылок); side service целиком
  против рендерера (с заглушками API Zepp); сборка `zeus build` и пакет для Cheetah Square.
- **Не проверено:** работа на реальных часах и в Termux; настоящий `mutool` (только его
  эмуляция); то, что Zepp на Android пускает side service на `http://127.0.0.1` (если
  нет — в настройках приложения можно указать другой адрес рендерера).
